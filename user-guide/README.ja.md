# Rearview ユーザーガイド

Rearviewは、macOS画面で選択した範囲の文字を認識して翻訳するメニューバーアプリです。日本語を韓国語に、または韓国語を日本語に翻訳できます。画面上の文字の認識と翻訳はすべてユーザーのMac上で処理され、画面内容が外部サーバーに送信されることはありません。

## 1. 使用前の準備

### 対応環境

- macOS 15以降
- Apple Silicon Mac

### 認識対象

Rearviewは、アプリやシステムが画面にレンダリングしたテキストを正確かつ高速に認識することを目指しています。手書きやカメラで撮影した画像もOCRで認識される場合がありますが、最適化の対象ではないため、認識精度は保証されません。

日本語→韓国語と韓国語→日本語の両方に対応しています。初期設定は日本語→韓国語で、`設定 → 一般 → 言語と翻訳`から翻訳方向を選択できます。

## 2. インストールと初回起動

### アプリのインストール

1. [GitHub Releases](https://github.com/bloodybear/rearview/releases)から最新の`Rearview.dmg`をダウンロードします。
2. DMGを開き、`Rearview.app`を`Applications`フォルダにドラッグします。
3. `Applications`フォルダからRearviewを起動します。

Rearviewは初回起動時にmacOSのセキュリティ確認が必要です。

### 初回起動がブロックされた場合

1. Rearviewを一度起動します。
2. **システム設定 → プライバシーとセキュリティ**を開きます。
3. **確認なしで開く**または**Open Anyway**を選択して、アプリを開きます。

システム設定の代わりに、ターミナルで次のコマンドを順番に実行することもできます。

```sh
xattr -dr com.apple.quarantine "/Applications/Rearview.app"
open "/Applications/Rearview.app"
```

### 画面収録の権限を許可する

1. Rearviewを起動します。
2. 権限案内のウィンドウからシステム設定を開きます。
3. **プライバシーとセキュリティ → 画面収録とシステムオーディオ録音**でRearviewを許可します。
4. 権限を変更した後、Rearviewを終了して再起動します。

### 翻訳言語パックを準備する

初めて翻訳を実行するとき、日本語・韓国語の翻訳言語パックが必要だという案内が表示される場合があります。案内に従って言語パックをインストールしてから、もう一度翻訳を実行します。

## 3. 初回翻訳

1. メニューバーのRearviewアイコンから**範囲を選択…**を選ぶか、`⌘⇧1`を押します。
2. 翻訳する文字を含む範囲をドラッグします。
3. OCRと翻訳が完了するまで待ちます。
4. ミラーウィンドウで翻訳結果を確認します。

**ヒント**

- 特定のアプリだけをキャプチャするには、ツールバーの**キャプチャするアプリを選択**（`⌘1`）で対象を指定します。

## 4. ミラーとオーバーレイの使用

### 表示方式を選択する

ツールバーの**ミラー／オーバーレイモードを切り替え**（`⌘2`）で表示方式を切り替えます。

| 方式 | 説明 |
| --- | --- |
| ミラー | 翻訳結果を別のウィンドウに表示します。 |
| オーバーレイ | 選択した画面範囲の上に翻訳結果を表示します。 |

### ミラーウィンドウを調整する

- **常に手前に表示**（`⌘6`）：ミラーウィンドウをほかのウィンドウより手前に保ちます。
- **選択範囲のサイズに追従**（`⌘8`）：選択範囲のサイズが変わるとミラーウィンドウのサイズも調整します。
- **翻訳背景の不透明度**：ミラーウィンドウの翻訳背景が見える度合いを調整します。
- **縮小**（`⌘-`）、**実際のサイズ**（`⌘0`）、**拡大**（`⌘=`）：ミラーの表示倍率を調整します。
- **余白を削除**（`⌘9`）：画像サイズを保ったまま、ミラーウィンドウの余白を減らします。

### オーバーレイを調整する

- 翻訳表示領域の不透明度を、アクティブ状態と非アクティブ状態でそれぞれ調整できます。
- ツールバーの不透明度を、アクティブ状態と非アクティブ状態でそれぞれ調整できます。
- **選択範囲のマウスイベントを無視**（`⌘6`）を有効にすると、オーバーレイはマウス入力を遮らず、背後のアプリに渡します。デフォルトで有効です。

### ミラーウィンドウをドッキングする

ミラーウィンドウを選択範囲の上、下、左、右にドッキングできます。

- **上にドッキング**（`⌘↑`）
- **下にドッキング**（`⌘↓`）
- **左にドッキング**（`⌘←`）
- **右にドッキング**（`⌘→`）

ミラーモードで同じ方向のドッキングショートカットをもう一度実行すると、ドッキングを解除します。オーバーレイモードではドッキングボタンとドッキングメニューを表示しませんが、方向ショートカットを押すとミラーモードに切り替わり、押した方向にドッキングします。範囲選択画面では修飾キーなしで`W`、`S`、`A`、`D`を使用できます。オーバーレイでプレビューしている場合も、方向キーを押すと同じ方法でミラーのドッキングプレビューに切り替わります。

## 5. 翻訳の更新とキャプチャ対象

### 自動更新と手動更新

デフォルトは**自動更新**です。画面の変化を検知すると、現在の選択範囲を再認識して翻訳します。

- ツールバーの**更新モードを切り替え**（`⌘5`）で、自動更新と手動更新を切り替えます。
- 自動更新では、**一時停止／再開／今すぐ翻訳**（`Space`）で翻訳を一時停止して再開できます。
- 手動更新では、**一時停止／再開／今すぐ翻訳**（`Space`）で現在の範囲を翻訳します。
- **今すぐ翻訳**（`⌘⌥1`）は、現在の範囲をすぐにキャプチャして翻訳します。

### キャプチャするアプリを選択する

ツールバーの**キャプチャするアプリを選択**（`⌘1`）でアプリを指定すると、そのアプリを翻訳対象として使用できます。選択できるのは、選択範囲の背後にあるアプリだけです。

### 対象アプリの移動を追跡する

`設定 → キャプチャとOCR → キャプチャ → 対象アプリの移動を追跡`を有効にすると、キャプチャ対象アプリのウィンドウが移動したときに翻訳範囲も一緒に移動します。

## 6. 翻訳結果の使用

### テキストを選択してコピーする

- **選択モード**（`⌘D`）を有効にすると、認識された原文と翻訳文を選択できます。
- **すべて選択**（`⌘A`）：現在認識されているテキストと翻訳文をすべて選択します。
- **選択範囲をコピー**（`⌘C`）：選択したテキストをコピーします。
- **コピーして選択解除**（`⌘X`）：選択したテキストをコピーしてから選択を解除します。
- **すべてコピー**（`⇧⌘C`）：現在の結果の原文と翻訳文を読み順にすべてコピーします。
- **テキストを検索**（`⌘F`）：現在認識されているテキストと翻訳文を検索します。

### 画像をコピーして保存する

- **画像をコピー**（`⌃⌘C`）：現在の翻訳範囲の画像をクリップボードにコピーします。
- **画像を保存**（`⌘S`）：現在の翻訳範囲の画像をPNGファイルとして保存します。
- 画像の保存フォルダとファイル名規則は`設定 → キャプチャとOCR → キャプチャ`で変更できます。

ファイル名規則には次のトークンを使用できます。

`{yyyy}`、`{MM}`、`{dd}`、`{HH}`、`{mm}`、`{ss}`、`{counter}`

### 原文以外のテキストを保護する

`原文以外のテキストを保護`が有効な場合、原文言語以外の英語・反対言語・数字を翻訳対象から除外し、そのまま保持します。その代わりテキストが分割され、翻訳の文脈が分かれる場合があります。

この機能を無効にすると、混在したテキスト全体を1つの翻訳単位として処理するため文脈を維持しやすくなりますが、英語・反対言語・数字も翻訳または変更される場合があります。デフォルトは無効です。

## 7. 設定

メニューバーのRearviewアイコンから**設定…**（`⌘,`）を選びます。

### 一般

| 設定 | 説明 |
| --- | --- |
| macOS起動時に自動実行 | ログイン後にRearviewを自動的に起動します。 |
| 表示言語 | メニュー、設定、翻訳UIで使用する言語を選択します。 |
| 翻訳方向 | 翻訳する原文言語と出力言語を選択します。デフォルトは日本語→韓国語です。 |
| 原文以外のテキストを保護 | 英語・反対言語・数字を翻訳から除外します。 |
| アップデートを自動確認 | 新しいアップデートをバックグラウンドで1日1回確認します。 |
| アップデートを自動ダウンロードしてインストール | アップデートをダウンロードし、次回アプリ終了時にインストールします。 |
| **すべての設定をリセット** | ショートカット、表示、キャプチャ、OCR、アップデート設定を初期値に戻します。macOSの権限は変更しません。 |

### ショートカット

ショートカット設定では、グローバルショートカット、翻訳セッションの操作、テキスト選択、ミラーサイズ、範囲選択のショートカットをそれぞれ変更または削除できます。新しいショートカットがすでに使用中の場合は、**使用中 — もう一度入力**が表示されます。

### 表示

ミラーとオーバーレイの表示方式、ミラーウィンドウの常に手前に表示する設定、背景の不透明度、選択範囲サイズへの追従、オーバーレイのマウス入力、選択範囲の枠線の不透明度を調整できます。

### キャプチャとOCR

| 設定 | 説明 |
| --- | --- |
| 画面キャプチャ速度 | 画面の変化を確認する速度です。範囲は1～30fpsです。 |
| 対象アプリの移動を追跡 | 対象アプリのウィンドウが移動すると翻訳範囲も移動します。 |
| 画像保存フォルダ | 保存したPNGファイルのデフォルトフォルダです。 |
| 画像ファイル名規則 | 保存する画像のファイル名形式です。 |
| OCRの最小間隔 | 画面が変化してから次のOCRを開始するまでの最小時間です。範囲は100～2000msです。 |
| ミラー更新方式 | 翻訳を一度に表示するか、完了した行から順に表示します。 |
| OCR実行方式 | 自動・手動モードで使用するOCRの流れを選択します。 |
| 認識言語 | OCRに渡す日本語・韓国語・英語の順序を選択します。 |
| 低信頼度ラインフィルター | 信頼度の低いOCR行を除外する基準です。 |

高度なOCR設定は、認識結果や処理時間を調整するときだけ変更してください。通常の使用ではデフォルト値を維持することをおすすめします。

## 9. トラブルシューティング

### アプリが起動しない

macOSのセキュリティ警告が表示された場合は、アプリを一度起動してから、**システム設定 → プライバシーとセキュリティ → 確認なしで開く**で実行を許可します。

### 画面収録の権限エラーが表示される

1. **システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音**を開きます。
2. Rearviewの権限を有効にします。
3. Rearviewを完全に終了してから、もう一度起動します。

### 翻訳が開始されない

- 選択範囲が1台のディスプレイ内に収まっていることを確認します。
- 選択範囲が小さすぎないこと、文字が切れていないことを確認します。
- 日本語・韓国語の翻訳言語パックが準備できていることを確認します。
- キャプチャするアプリを指定した場合は、そのアプリが起動していることを確認します。
- 画面に変化がない場合は、自動更新が一時停止されていないことを確認します。

### 文字をうまく認識できない

- 文字が含まれる範囲を少し広めに選択します。
- 小さい文字やぼやけた文字が多い場合は、高度なOCRの入力倍率を調整します。
- `認識言語`の順序を画面の主な言語に合わせます。
- 低信頼度ラインフィルターの値を高くしすぎていないか確認します。

### オーバーレイが背後のアプリのクリックを妨げる

`設定 → 表示 → オーバーレイ → 選択範囲のマウスイベントを無視`が有効になっていることを確認します。ツールバーの**モード別画面動作を切り替え**（`⌘6`）でも切り替えられます。

### 対象アプリを移動しても翻訳範囲が追従しない

`設定 → キャプチャとOCR → キャプチャ → 対象アプリの移動を追跡`を有効にし、キャプチャするアプリが正しく指定されていることを確認します。

### 画像を保存できない

画像保存フォルダが存在し、書き込み可能であることを確認します。`設定 → キャプチャとOCR → キャプチャ → 画像保存フォルダ`で別のフォルダを選択できます。

### ショートカットを設定できない

別の機能やアプリがそのショートカットを使用していないか確認します。設定画面に**使用中 — もう一度入力**と表示された場合は、別のキーの組み合わせを入力してください。必要に応じて**すべての設定をリセット**でRearviewのショートカットをデフォルトに戻せます。
