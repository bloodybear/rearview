# Rearview 사용 설명서

Rearview는 macOS 화면에서 선택한 영역의 글자를 인식하고 번역하는 메뉴바 앱입니다. 일본어를 한국어로 번역하거나 한국어를 일본어로 번역할 수 있습니다. 화면의 글자 인식과 번역은 모두 사용자의 Mac에서 처리되며, 화면 내용은 외부 서버로 전송되지 않습니다.

## 1. 사용 전 준비

### 지원 환경

- macOS 15 이상
- Apple Silicon Mac

### 인식 대상

Rearview는 앱이나 시스템이 화면에 렌더링한 텍스트를 정확하고 빠르게 인식하는 것을 목표로 합니다. 손글씨나 카메라로 촬영한 이미지도 OCR로 인식될 수 있지만, 최적화 대상이 아니므로 인식 정확도를 보장하지 않습니다.

일본어→한국어와 한국어→일본어 번역을 모두 지원합니다. 기본 설정값은 일본어→한국어이며, `설정 → 일반 → 언어 및 번역`에서 번역 방향을 선택할 수 있습니다.

## 2. 설치 및 첫 실행

### 앱 설치

1. [GitHub Releases](https://github.com/bloodybear/rearview/releases)에서 최신 `Rearview.dmg`를 내려받습니다.
2. DMG를 열고 `Rearview.app`을 `Applications` 폴더로 드래그합니다.
3. `Applications` 폴더에서 Rearview를 실행합니다.

Rearview는 처음 실행할 때 macOS의 보안 확인이 필요합니다.

### 첫 실행이 차단될 때

1. Rearview를 한 번 실행합니다.
2. **시스템 설정 → 개인정보 보호 및 보안**을 엽니다.
3. **확인 없이 열기** 또는 **Open Anyway**를 선택한 뒤 앱을 엽니다.

시스템 설정 대신 터미널에서 다음 명령어를 순서대로 실행할 수도 있습니다.

```sh
xattr -dr com.apple.quarantine "/Applications/Rearview.app"
open "/Applications/Rearview.app"
```

### 화면 기록 권한 허용

1. Rearview를 실행합니다.
2. 권한 안내 창에서 시스템 설정을 엽니다.
3. **개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음**에서 Rearview를 허용합니다.
4. 권한을 바꾼 뒤 Rearview를 종료하고 다시 실행합니다.

### 번역 언어 팩 준비

번역을 처음 실행할 때 일본어·한국어 번역 언어 팩이 필요하다는 안내가 표시될 수 있습니다. 안내에 따라 언어 팩을 설치한 뒤 번역을 다시 실행합니다.

## 3. 첫 번역 실행

1. 메뉴바의 Rearview 아이콘에서 **영역 선택…**을 선택하거나 `⌘⇧1`을 누릅니다.
2. 번역할 글자가 포함된 영역을 드래그합니다.
3. OCR과 번역이 완료될 때까지 기다립니다.
4. 미러창에서 번역 결과를 확인합니다.

**팁**

- 특정 앱만 캡처하려면 툴바의 **캡처할 앱 선택** (`⌘1`)에서 대상 앱을 지정하세요.

## 4. 미러와 오버레이 사용

### 표시 방식 선택

툴바의 **미러/오버레이 모드 전환** (`⌘2`)으로 표시 방식을 전환합니다.

| 방식 | 설명 |
| --- | --- |
| 미러 | 번역 결과를 별도 창에 표시합니다. |
| 오버레이 | 선택한 화면 영역 위에 번역 결과를 표시합니다. |

### 미러창 조정

- **항상 위** (`⌘6`): 미러창을 다른 창보다 위에 유지합니다.
- **선택 영역 크기 연동** (`⌘8`): 선택 영역의 크기가 바뀔 때 미러창 크기도 함께 조정합니다.
- **번역 배경 불투명도**: 미러창의 번역 배경이 비치는 정도를 조절합니다.
- **축소** (`⌘-`), **실제 크기** (`⌘0`), **확대** (`⌘=`): 미러 표시 배율을 조절합니다.
- **여백 제거** (`⌘9`): 이미지 크기는 유지하면서 미러창의 남는 여백을 줄입니다.

### 오버레이 조정

- 활성·비활성 상태의 번역 표시 영역 불투명도를 각각 조절할 수 있습니다.
- 활성·비활성 상태의 툴바 불투명도를 각각 조절할 수 있습니다.
- **선택 영역 마우스 이벤트 무시** (`⌘6`)를 켜면 오버레이가 마우스 입력을 가로채지 않고 뒤에 있는 앱으로 전달합니다. 기본값은 켜짐입니다.


### 미러창 도킹

미러창을 선택 영역의 위·아래·왼쪽·오른쪽에 붙일 수 있습니다.

- **위쪽에 도킹** (`⌘↑`)
- **아래쪽에 도킹** (`⌘↓`)
- **왼쪽에 도킹** (`⌘←`)
- **오른쪽에 도킹** (`⌘→`)

미러 모드에서 같은 방향의 도킹 단축키를 다시 실행하면 도킹을 해제합니다. 오버레이 모드에서는 도킹 버튼과 오버플로 메뉴를 표시하지 않지만, 이 방향 단축키를 누르면 미러 모드로 전환하면서 누른 방향으로 도킹합니다. 선택 영역 화면에서는 보조 키 없이 `W`, `S`, `A`, `D`를 사용할 수 있으며, 오버레이로 프리뷰 중이어도 방향 키를 누르면 같은 방식으로 미러 도킹 프리뷰로 전환합니다.

## 5. 번역 갱신과 캡처 대상

### 자동 갱신과 수동 갱신

기본값은 **자동 갱신**입니다. 화면 변화를 감지하면 현재 선택 영역을 다시 인식하고 번역합니다.

- 툴바의 **갱신 모드 전환** (`⌘5`)으로 자동·수동 갱신을 전환합니다.
- 자동 갱신에서는 **일시정지/재생/즉시 번역** (`Space`)으로 번역을 멈췄다가 다시 시작할 수 있습니다.
- 수동 갱신에서는 **일시정지/재생/즉시 번역** (`Space`)으로 현재 영역을 번역합니다.
- **즉시 번역** (`⌘⌥1`)은 현재 영역을 즉시 캡처하고 번역합니다.

### 캡처할 앱 선택

툴바의 **캡처할 앱 선택** (`⌘1`)에서 특정 앱을 지정하면 해당 앱을 번역 대상으로 사용할 수 있습니다. 선택할 수 있는 앱은 선택 영역 뒤에 있는 앱으로 제한됩니다.

### 타겟 앱 이동 추적

`설정 → 캡처 및 OCR → 캡처 → 타겟 앱 이동 추적`을 켜면 캡처 대상 앱의 창이 이동할 때 번역 영역도 함께 이동합니다.

## 6. 번역 결과 사용

### 텍스트 선택과 복사

- **선택 모드** (`⌘D`)를 켜면 인식된 원문과 번역문을 선택할 수 있습니다.
- **전체 선택** (`⌘A`): 현재 인식된 텍스트와 번역문을 모두 선택합니다.
- **선택 복사** (`⌘C`): 선택한 텍스트를 복사합니다.
- **복사 후 선택 해제** (`⌘X`): 선택한 텍스트를 복사한 뒤 선택을 해제합니다.
- **전체 복사** (`⇧⌘C`): 현재 결과의 원문과 번역문을 읽기 순서대로 모두 복사합니다.
- **텍스트 검색** (`⌘F`): 현재 인식된 텍스트와 번역문을 검색합니다.

### 이미지 복사와 저장

- **이미지 복사** (`⌃⌘C`): 현재 번역 영역 이미지를 클립보드에 복사합니다.
- **이미지 저장** (`⌘S`): 현재 번역 영역 이미지를 PNG 파일로 저장합니다.
- 이미지 저장 폴더와 파일명 규칙은 `설정 → 캡처 및 OCR → 캡처`에서 변경합니다.

파일명 규칙에는 다음 토큰을 사용할 수 있습니다.

`{yyyy}`, `{MM}`, `{dd}`, `{HH}`, `{mm}`, `{ss}`, `{counter}`

### 원문 외 텍스트 보호

`원문 외 텍스트 보호`가 켜져 있으면 원문 언어 이외의 영어·반대 언어·숫자를 번역 대상에서 제외하고 원문 그대로 유지합니다. 대신 텍스트가 분리되어 번역 문맥이 나뉠 수 있습니다.

이 기능이 꺼져 있으면 혼합된 텍스트 전체를 하나의 번역 단위로 처리해 문맥을 유지할 수 있지만, 영어·반대 언어·숫자도 번역되거나 바뀔 수 있습니다. 기본값은 꺼짐입니다.

## 7. 설정

메뉴바의 Rearview 아이콘에서 **설정…** (`⌘,`)을 선택합니다.

### 일반

| 설정 | 설명 |
| --- | --- |
| macOS 시작 시 자동 실행 | 로그인 후 Rearview를 자동으로 실행합니다. |
| 표시 언어 | 메뉴, 설정, 번역 UI에 사용할 언어를 선택합니다. |
| 번역 방향 | 번역할 원문 언어와 번역 언어를 선택합니다. 기본값은 일→한입니다. |
| 원문 외 텍스트 보호 | 영어·반대 언어·숫자를 번역에서 제외합니다. |
| 업데이트 자동 확인 | 새 업데이트를 백그라운드에서 하루에 한 번 확인합니다. |
| 업데이트 자동 다운로드 및 설치 | 업데이트를 내려받고 다음 앱 종료 시 설치합니다. |
| **모든 설정 초기화** | 단축키·표시·캡처·OCR·업데이트 설정을 기본값으로 되돌립니다. macOS 권한은 바뀌지 않습니다. |

### 단축키

단축키 설정에서는 전역 단축키, 번역 세션 제어, 텍스트 선택, 미러 크기, 영역 선택 단축키를 각각 변경하거나 제거할 수 있습니다. 새 단축키가 이미 사용 중이면 **사용 중 — 다시 입력**이 표시됩니다.

### 화면 표시

미러·오버레이 표시 방식, 미러창의 항상 위 설정, 배경 불투명도, 선택 영역 크기 연동, 오버레이 마우스 입력, 선택 영역 테두리 불투명도를 조절합니다.

### 캡처 및 OCR

| 설정 | 설명 |
| --- | --- |
| 화면 캡처 속도 | 화면 변화를 확인하는 속도입니다. 1–30fps 범위입니다. |
| 타겟 앱 이동 추적 | 대상 앱 창이 이동할 때 번역 영역도 이동합니다. |
| 이미지 저장 폴더 | 저장한 PNG 파일의 기본 폴더입니다. |
| 이미지 파일명 규칙 | 저장되는 이미지의 파일명 형식입니다. |
| OCR 최소 간격 | 화면이 변한 뒤 다음 OCR을 시작하기까지의 최소 시간입니다. 100–2000ms 범위입니다. |
| 미러 갱신 방식 | 번역을 한 번에 표시하거나 완료되는 줄부터 점진적으로 표시합니다. |
| OCR 실행 방식 | 자동·수동 모드에서 사용할 OCR 흐름을 선택합니다. |
| 인식 언어 | OCR에 전달할 일본어·한국어·영어 순서를 선택합니다. |
| 저신뢰도 라인 필터 | 신뢰도가 낮은 OCR 줄을 제외하는 기준입니다. |

고급 OCR 설정은 인식 결과와 처리 시간을 조정할 때만 변경하세요. 일반적인 사용에서는 기본값을 유지하는 것이 좋습니다.

| **왼쪽에 도킹** | `A` |
| **오른쪽에 도킹** | `D` |

오버레이 상태에서도 위 방향 키를 누르면 미러 모드와 해당 방향 도킹으로 전환합니다. 오버레이에서는 도킹 버튼과 도킹 메뉴를 표시하지 않습니다.

## 9. 문제 해결

### 앱이 실행되지 않음

macOS의 보안 경고가 표시되면 앱을 한 번 실행한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**에서 실행을 허용합니다.

### 화면 기록 권한 오류가 표시됨

1. **시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음**을 엽니다.
2. Rearview 권한을 켭니다.
3. Rearview를 완전히 종료한 뒤 다시 실행합니다.

### 번역이 시작되지 않음

- 선택 영역이 한 모니터 안에 있는지 확인합니다.
- 선택 영역이 너무 작거나 글자가 잘리지 않았는지 확인합니다.
- 일본어·한국어 번역 언어 팩이 준비되어 있는지 확인합니다.
- 캡처할 앱을 지정했다면 해당 앱이 실행 중인지 확인합니다.
- 화면 변화가 없는 경우 자동 갱신이 일시정지되지 않았는지 확인합니다.

### 글자를 잘 인식하지 못함

- 글자가 포함된 영역을 조금 넓게 선택합니다.
- 작은 글자나 흐릿한 글자가 많은 경우 고급 OCR의 입력 배율을 조정합니다.
- `인식 언어` 순서를 화면의 주된 언어에 맞춥니다.
- 저신뢰도 라인 필터 값을 너무 높게 설정하지 않았는지 확인합니다.

### 오버레이가 뒤에 있는 앱의 클릭을 막음

`설정 → 화면 표시 → 오버레이 → 선택 영역 마우스 이벤트 무시`가 켜져 있는지 확인합니다. 툴바의 **모드별 화면 동작 전환** (`⌘6`)으로도 전환할 수 있습니다.

### 대상 앱을 옮겼는데 번역 영역이 따라가지 않음

`설정 → 캡처 및 OCR → 캡처 → 타겟 앱 이동 추적`을 켜고, 캡처할 앱이 올바르게 지정되어 있는지 확인합니다.

### 이미지를 저장할 수 없음

이미지 저장 폴더가 존재하고 쓰기 가능한지 확인합니다. `설정 → 캡처 및 OCR → 캡처 → 이미지 저장 폴더`에서 다른 폴더를 선택할 수 있습니다.

### 단축키를 지정할 수 없음

다른 기능이나 앱이 사용 중인 단축키인지 확인합니다. 설정 화면에 **사용 중 — 다시 입력**이 표시되면 다른 키 조합을 입력하세요. 필요하면 **모든 설정 초기화**로 Rearview 단축키를 기본값으로 되돌릴 수 있습니다.
