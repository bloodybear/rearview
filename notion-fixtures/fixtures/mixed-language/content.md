# 日本語を中心にした混在文の検査

このページだけは、言語判定と非原文の保持を確認するために韓国語と英語を意図的に含めています。日本語を韓国語へ翻訳するとき、すでに韓国語の部分を再翻訳したり、英語の識別子を書き換えたりしないか確認します。

## M01｜一行に日本語と韓国語を併記

保存しても公開されません。 / 저장해도 공개되지 않습니다.

この操作は取り消せません。 / 이 작업은 취소할 수 없습니다.

公開する前に確認してください。 / 공개하기 전에 확인해 주세요.

## M02｜同じ意味の二つの段落を結合しない

申請は受け付けましたが、まだ承認されていません。

신청은 접수했지만 아직 승인되지 않았습니다.

## M03｜文の途中で言語が切り替わる

担当者は「검토 중」と回答しましたが、これは承認済みという意味ではありません。

이 안내에서 「公開しないでください」는 공개 금지를 뜻합니다。公開してよい、という意味に変えないでください。

日本語の説明 → 한국어 보충 설명 → English identifier: review_pending → 日本語の結論：まだ公開できません。

## M04｜製品名・API・URL・変数名

Notion API の `last_edited_time` は、本文そのものではなく更新時刻です。`page_id` と `data_source_id` は別の識別子なので、同じ値だと解釈しないでください。

macOS の Accessibility API で取得した `AXFrame` と、OCR の bounding box を比較します。`x=128, y=64, width=320, height=48` の数値と順番は変更しないでください。

エラーコード `E_TIMEOUT` が出た場合でも、`https://example.com/review?lang=ja&mode=draft` を勝手に別の URL へ書き換えないでください。

## M06｜かな・半角・結合文字・似ている字

ひらがなだけのあんないです。まだほぞんしないでください。

カタカナ：ユーザー・サーバー・データベース・キャンセル

半角カナ：ﾕｰｻﾞｰ・ｻｰﾊﾞｰ・ﾃﾞｰﾀﾍﾞｰｽ・ｷｬﾝｾﾙ

全角の「ガイド」と、結合文字の「ガイド」、半角の「ｶﾞｲﾄﾞ」は、同じ語を異なる文字列で表しています。

「ー」と「一」、「ロ」と「口」、「カ」と「力」、「０」と「O」、「１」と「l」を取り違えないでください。

## M07｜数字・単位・比較・否定

上限は 1,200 件です。1.200 件という小数ではありません。

料金は ¥1,280／月です。₩1,280／月でも、$1,280／月でもありません。

温度は −5 °C 以上、5 °C 未満です。「以上」と「未満」を反転させないでください。

割引率は 15% から 5% に下がりました。価格が 10% 下がったという説明ではありません。

## M08｜絵文字と合成された文字

👩‍💻 担当者が確認中です。承認されたわけではありません。

👨‍👩‍👧‍👦 家族全員の同意が必要です。代表者一名だけでは足りません。

🇯🇵 → 🇰🇷 日本語から韓国語へ翻訳します。🇰🇷 → 🇯🇵 は別の翻訳方向です。

👍🏽 確認済み　⚠️ 未確認　❤️ お気に入り　✅ 完了　❌ 未完了

## M09｜韓国語だけの対照群

이 문단은 한국어 원문입니다. 일본어→한국어 모드에서는 일본어 문장으로 오인하지 않아야 합니다.

설정을 저장하지 않으면 변경 내용이 사라집니다. 저장해도 자동으로 공개되지는 않습니다.
